NUTRIMAX CLIENTES - APLICACION WEB INSTALABLE

Esta aplicación es una PWA: funciona como una aplicación en el celular, pero no necesita Play Store.

FUNCIONES:
- Registrar negocio, encargado de compras, teléfono, dirección, ciudad y barrio/zona.
- Buscar clientes.
- Filtrar por ciudad.
- Editar y eliminar clientes.
- Botón para llamar al cliente.
- Guarda los datos localmente en el dispositivo.
- Se puede instalar en la pantalla de inicio.

IMPORTANTE:
Los datos quedan guardados en el navegador/dispositivo. Para una versión empresarial con sincronización entre celular y computador, usuarios, copias de seguridad automáticas y acceso desde varios dispositivos, se debe agregar una base de datos en la nube.

PARA EJECUTARLA EN UN COMPUTADOR:
1. Se recomienda usar Chrome.
2. Para una prueba sencilla, se puede abrir index.html, aunque algunas funciones PWA requieren servir la carpeta desde un servidor local.
3. Para instalarla en el celular de forma correcta, publica esta carpeta en un hosting con HTTPS (por ejemplo GitHub Pages, Netlify o similar) y abre la dirección desde el celular.
